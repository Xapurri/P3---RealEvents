# License not selected yet

A software license must be chosen before publishing Real Events as an open-source repository.

Do not replace this file with a license automatically without deciding:

- whether modification and redistribution should be permitted;
- whether derivative works must remain open;
- whether attribution is required;
- whether compiled releases may be redistributed separately.

Common candidates to consider are MIT, Apache-2.0, or GPL-3.0, but the project owner should choose deliberately.
